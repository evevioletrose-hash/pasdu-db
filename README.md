# pasdu-db

An engine-independent archive of creative works and associated documents, intended for human readers and software consumers across projects.

## Status

Initialized. The document format and metadata contract are pending collaborative review; no schema is normative yet.

## Design goals

- Preserve original works independently of commentary, interpretations, and derived representations.
- Use durable, human-readable, version-controlled formats and stable record identities.
- Retain provenance and distinguish versions, uncertain dates, and explicitly authored context from inference.
- Allow cross-project references without depending on any particular engine, application, or database.
- Keep generated indexes and application-specific resources reproducible from the archive.

## Publication boundary

This repository is public at initialization. Do not add private or unpublished material without the owner's explicit decision about publication and visibility. Git history may retain content even after deletion from the current branch.

The initial commit intentionally contains no corpus material.
